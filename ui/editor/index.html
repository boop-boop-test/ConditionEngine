ConditionEngine

dials, conditions, values

Open with F10

Make a value that changes on its own

A dial is a number. Rules move it: an event switches it on, a condition sets it, a rate wears it down every second. Every dial is also a ConditionEngine value ($name), so outfits, faces and anything else that reads conditions can react to it.

Thresholds: a change across one sends Dials_Changed even when a rate moves it. Feeds: this dial becomes a source of those combined values (e.g. $hunger for players without a survival mod).

Rules

Each rule: when something happens, do something to the dial. Rules run top to bottom.

Conditions it names

Named conditions any mod can use as @Name. Write >= 75 to compare this dial, an option label, or a full expression.
